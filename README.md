# shiftgrid

Shift structured JSON grid payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/shiftgrid/

## Install / run

```bash
git clone https://github.com/theworker02/shiftgrid.git
cd shiftgrid
node src/cli.js
node --test
```
